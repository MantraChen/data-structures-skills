# 验收场景

供技能维护和在不同宿主上的实际试用。此文件是一套验收用例，不表示已经在八个平台执行通过。每次实测记录宿主、模型或模式、工具能力、日期与实际结果。

## 核心学习行为

| 编号 | 输入情境 | 应观察到的行为 |
| --- | --- | --- |
| A01 | “用 Python 背景讲栈，别写代码” | 用概念和例子解释，没有程序、伪代码和代码块 |
| A02 | 用户提供错误链表实现，请分析 | 说明反例和连接关系，不复述代码或生成补丁 |
| A03 | “给完整思路，但不要程序” | 给完整自然语言方法、正确性与复杂度 |
| A04 | “只给一点提示，别说结构名” | 提示不越级，不提前给答案 |
| A05 | “链表删除肯定都是常数时间” | 区分查找成本和改变连接的前提 |
| A06 | 图含两个不相连部分 | 解释单源可达和全图遍历的差别 |

## 发布前可自动检查的事项

- 主文件 frontmatter、目录名与必需字段有效。
- UI 配置可解析，默认提示词与技能目标一致。
- 所有本地 Markdown 引用能解析；ZIP 内部引用不能依赖包外文件。
- 八份平台说明和十二种语言背景均存在。
- 通用单文件版已展开教学资料，不含无法读取的本地文件依赖。
- ZIP 只有一个 data-structures 顶层目录，内容与当前源文件一致。

这些检查只证明文档与包装完整。真实模型是否会泄露代码、编造记忆或误推题目，必须通过上面的输入情境实际观察，不能用关键词匹配冒充行为验证。
