## 自行集成 API 时

DeepSeek 的对话接口文档包含 system 类型消息，可按所选接口把教学约束放在指令消息中，再提供用户资料和当前任务。本文提供接入原则，不包含 API 程序或凭据配置。[DeepSeek 官方消息协议](https://api-docs.deepseek.com/api/create-chat-completion/)

聊天产品的联网开关与自行集成 API 时的工具配置不是同一件事；需要在当前环境验证可用能力。
