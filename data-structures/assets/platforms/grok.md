# Grok 适配

核验日期：2026-10-28。

## 接入方式

复制[通用启动指令](../portable-core.md)到普通聊天。需要完整教学资料时，按当前界面支持的方式提供单文件版；官方功能概览列出了聊天和文件输入能力。具体格式及账户限制仍以当前界面为准。[Grok 官方概览](https://docs.x.ai/grok/overview)

这份适配交付的是可供 Grok 读取的教学规则，不把其他宿主的 ZIP 导入流程写成 Grok 的既定流程。若使用不同的 Grok 产品或 agent 外壳，应按该宿主实际支持的文件和工具方式加载。

## 启动示例

> 按我提供的数据结构学习规则工作。我使用 JavaScript，想理解队列和 BFS 的关系，只讲概念。推荐题目时请核验官方题面；无法访问时说明哪些信息未确认。

## 接入后检查

不要仅凭 Grok 的品牌推断本会话一定联网。检查题目来源、提交语言和是否真实使用学习记录；若不能长期保存，输出交接摘要。使用[验收场景](../../references/acceptance-scenarios.md)检查行为。
