# Kimi 适配

核验日期：2026-10-28。

## 普通聊天

复制[通用启动指令](../portable-core.md)。需要完整规则时，以当前界面允许的文字或附件形式提供单文件版，再明确要求按规则进行学习辅导。只有模型实际读取到的资料才能用于判断学习进展。

## 对话 API 或自有宿主

Kimi 官方接口接受对话消息，并按当前模型和接口定义消息角色与工具选项。自行集成时按该协议提供教学规则和学习资料，不直接套用其他厂商的私有配置或本地目录约定。[Kimi 官方消息协议](https://platform.kimi.ai/docs/api/chat)

本适配不依赖固定上下文长度，也不把能处理长文本等同于已经拥有个人长期 memory。

## 启动示例

> 按无代码数据结构学习规则，结合我粘贴的学习摘要继续辅导。我目前学 Rust，能解释栈，但图遍历中的访问状态还不清楚，请先讲这一点。

## 接入后检查

使用[验收场景](../../references/acceptance-scenarios.md)确认旧摘要与本次陈述冲突时采用新信息，并且没有把附件中的例子误记为用户真实经历。
