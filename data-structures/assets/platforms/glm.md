# GLM 适配

核验日期：2026-10-28。

## 普通聊天

复制[通用启动指令](../portable-core.md)并提供学习信息。需要完整内容时使用单文件版；智谱相关聊天产品、Z.AI 和第三方宿主的文件或工具入口按各自界面处理，不假定账户能力互通。

## 对话 API

Z.AI 官方对话接口文档列出 system、user、assistant 和 tool 等消息类型。自行集成时可在支持的指令消息中放置教学约束，并在用户消息中提供当前任务与学习资料。[GLM 官方消息协议](https://docs.z.ai/api-reference/llm/chat-completion)

普通文本适配不需要输出调用代码，也不会自动创建模型账号、联网工具或长期记忆。

## 启动示例

> 我使用 C#，今天只有二十分钟，想弄清哈希表与有序结构的区别。只讲概念；如果推荐题目，请控制数量并解释为什么适合当前基础。

## 接入后检查

用[验收场景](../../references/acceptance-scenarios.md)检查小时间预算、未知评分和无记忆时的行为。不要将接口格式支持当作已完成教学行为测试。
